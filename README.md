# NexaCV AI

NexaCV AI is an intelligent career assistant Android app designed to help users create multiple professional profiles and generate ATS-optimized resumes and cover letters.

**Note: This project is currently under active development.**

## Features (Planned)
- Multi-profile management under a single account.
- AI-assisted CV and cover letter refinement.
- Local, offline-first templating system using Jetpack Compose.
- Secure authentication via Firebase.
- PDF Exporting.
